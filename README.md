# 📊 Log Anomaly Detection App

## 📌 Опис проєкту

Даний проєкт представляє собою програмне забезпечення для аналізу лог-файлів та виявлення аномалій із використанням алгоритмів машинного навчання.

Програма дозволяє користувачу завантажити лог-файл, виконати його аналіз та отримати результати у вигляді таблиці, графіка та звіту.

---

## ⚙️ Використані технології

- Python  
- Tkinter (графічний інтерфейс)  
- pandas (обробка даних)  
- scikit-learn (алгоритм Isolation Forest)  
- matplotlib (побудова графіків)
